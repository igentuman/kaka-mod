# Kaka Mod Information

## Summary
A Minecraft Forge mod that adds "kaka" (pooping) functionality to the game. The mod is designed for Minecraft version 1.20.1 and is available on CurseForge.

## Structure
- **src/main/java**: Contains Java source code organized in the com.igentuman.kaka package
- **src/main/resources**: Contains game assets, configurations, and metadata
- **src/generated/resources**: Contains resources generated by data generators
- **gradle**: Contains Gradle wrapper files for build system

## Language & Runtime
**Language**: Java
**Version**: Java 17
**Build System**: Gradle with ForgeGradle
**Package Manager**: Gradle/Maven

## Dependencies
**Main Dependencies**:
- Minecraft Forge 1.20.1-47.4.0
- Parchment Mappings 2023.09.03-1.20.1

**Development Dependencies**:
- org.parchmentmc.librarian.forgegradle
- org.spongepowered.mixin (0.7.+)
- com.github.johnrengelman.shadow (7.0.0)

## Build & Installation
```bash
# Build the mod
./gradlew build

# Run the client for testing
./gradlew runClient

# Generate data resources
./gradlew runData

# Create the distributable JAR file
./gradlew jar
```

## Mod Configuration
**Mod ID**: kaka
**Version**: 1.4.4
**Group**: com.igentuman.kaka

## Features
**Main Components**:
- KakaDemon: A boss entity with custom attributes
- KakaBlock: Custom block implementation
- Custom animations and events system
- Data generation for assets and resources
